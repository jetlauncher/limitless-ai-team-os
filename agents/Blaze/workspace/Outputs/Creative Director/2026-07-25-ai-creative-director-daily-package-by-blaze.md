หนึ่ง Permission ต่ำสุดเท่าที่จำเป็น ถ้า agent ตอบลูกค้า ไม่ควรมีสิทธิ์ refund เอง ถ้า agent อ่านเอกสาร ไม่ควรลบไฟล์ได้ Prompt policy: “You may draft, classify, and recommend. You may not send, delete, refund, or change records without human approval.”
สอง Sandbox แยกจากระบบจริง ทดสอบใน copy ของข้อมูล ไม่ใช่ production database
สาม Approval gate สำหรับ action ที่กระทบเงิน ลูกค้า ข้อมูลส่วนบุคคล หรือ public channel เช่น ส่งอีเมลจริง โอนเงิน เปลี่ยนราคา publish post ต้องมีคนกด approve

ห้า Incident drill ถ้า agent ทำผิด ต้องรู้ทันทีว่าจะ pause key, revoke token, export logs, แจ้ง owner, rollback ยังไง
ตัวอย่าง workflow support: agent อ่าน ticket → เสนอคำตอบ → ถ้าเป็นคำถามทั่วไปส่ง draft ให้มนุษย์ approve → ถ้า refund เกิน 500 บาท escalate → ถ้าขอข้อมูลส่วนตัว mask ก่อนให้ model

English: The five guardrails are least privilege, sandboxing, approval gates, readable logs, and incident drills. Treat AI agents like junior employees with system access.
