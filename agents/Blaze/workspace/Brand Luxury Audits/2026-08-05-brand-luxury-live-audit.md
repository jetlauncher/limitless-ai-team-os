## Micro-Upgrades (Prioritized)

### Upgrade 1: Remove "Subscribe" Button from Channel Header — Priority 🔴 CRITICAL

**Exact change:** In YouTube Studio → Customization → Layout → "Branding" section, uncheck "Show channel name and description" in the watermark (remove overlay subscribe button). Below the profile info, there is no native setting to hide the Subscribe button — but we can add branded channel art that visually absorbs it into the banner design, making it read as an intentional CTA rather than a raw red button. Alternatively, create a clean black bar across the bottom of the banner image that overlaps the button area on all viewport widths.

**Why it increases luxury:** The red "Subscribe" button is the single highest-dilution element on the entire channel page. It triggers "YouTube growth hack / desperate creator" associations instantly. Luxury signals begin with **absence of urgency cues** — expensive brands never shout. Removing or visually absorbing this button makes the first impression editorial, not transactional.

**Quick implementation:** Edit banner in Canva/Figma → extend the dark area 10px lower to create a solid black band where the Subscribe button sits on desktop view. This "hides" the red button under the artwork while keeping CTA copy ("Follow us on YouTube") inside the visible area.

### Upgrade 2: Launch a "Authority Stack" Thumbnail Series — Priority 🟡 HIGH

**Exact change:** For the next 3 videos, produce thumbnails using **only** this system:
- Background: pure #17181A or near-black (#0D0D0D)
- Jet portrait: left third, natural lighting, no filters, wearing black or charcoal
- Text overlay: white text only (Poppins/SF Pro display), max 8 words, positioned in upper-right negative space
- Zero gradients, zero product logos, zero badges, zero price numerals, zero emojis, zero colored accents

**Why it increases luxury:** The Popular Videos row already proves this system works — 49K–107K views across all entries. Recent uploads are actively fighting that authority signal by using saturated gradients and tool-aggregator layouts (the exact opposite of luxury). Every new upload should reinforce the editorial stack, not dilute it. Restraint is the premium currency.

**Quick implementation:** Create a single Canva template in Limitless Club brand colors (#17181A BG, white text, Jet portrait left) and duplicate it for all upcoming videos. Only change text per video; keep composition identical across the series for instant authority recognition.

### Upgrade 3: Fix Product-Over-Person Hierarchy — Priority 🟡 HIGH

**Exact change:** Never place a product logo (KIMI, Manus, ChatGPT, etc.) above or larger than Jet's portrait in any thumbnail. If naming a product is necessary, place the product name as small white text (60pt max) in the lower-left corner, below Jet's shoulder. Jet Trinupab = the authority; every tool = secondary reference.

**Why it increases luxury:** When a tool logo dominates the visual hierarchy, the thumbnail reads as "aggregator / comparison site" — low-status content positioning. When Jet is the clear visual anchor, it reads as "thought leader reviewing tools on his terms." Luxury brands center the **human authority**, not the featured brand/product.

**Quick implementation:** Add a rule to the thumbnail template: "Jet's face > 70% of thumbnail width; product names appear only in small caption text, never as standalone graphics."

### Upgrade 4: Replace Gold Accent Text White — Priority 🟢 MEDIUM

**Exact change:** In the banner and any thumbnail that uses gold (#94764A or similar), consider replacing with white-only treatment (or use #94764A at only 50% opacity if gold must appear). Remove the large serif gold from "เก่ง AI" in the banner.

**Why it increases luxury:** Gold-on-black is a well-known "luxury" trope in low-end design contexts. Authentic premium brands rarely deploy gold as a primary color — they deploy typography, negative space, and photographic quality instead. White-on-black reads as more confident (it doesn't need decorative accents to feel valuable).

**Quick implementation:** Open current banner art → select gold text elements → change fill color to #FFFFFF at the same weight/size. Keep a gold backup version for comparison.

### Upgrade 5: Standardize Thumbnail Aspect Ratio + Duration Badge Consistency — Priority 🟢 MEDIUM

**Exact change:** All thumbnails must use exactly 1280×720px with rounded corner masks on photo cutouts to create subtle frame depth. Duration badges (timecodes) should use the same system across every thumbnail: white text, dark semi-transparent pill background, positioned in bottom-right corner consistently.

**Why it increases luxury:** Inconsistency signals "assembled by committee at different times." Uniformity — down to badge positioning — signals a **professional editorial system**. High-end media properties treat every frame as part of a single design language. Small visual tithes build the perception of expensive production quality without costing anything extra.

**Quick implementation:** Add a rounded-corner mask effect in Canva for all photo cutouts. Create a "duration badge" graphic element and paste it identically into each thumbnail's bottom-right corner.
