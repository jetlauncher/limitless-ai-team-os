## 2. Confluence agents can now act inside the system of record—not just chat about it

- **Verified sources/date:** Atlassian’s official product post and X announcement — **2026-08-11 04:59 Bangkok / 2026-08-10 21:59 UTC**.[2][3]
- **What changed — fact:** Agents can create and edit Confluence pages, comment, label, set status, create whiteboards/databases, and work through Rovo MCP from Claude, Cursor, ChatGPT, or an IDE. Atlassian says agents operate within user permissions, leave reversible version history, and appear in analytics. It also reports more than **5 million agent invocations per month**, more than **200,000 customer hours saved in February**, and **44% higher accuracy with 48% fewer tokens** when grounded in Teamwork Graph context; these figures are company-reported, not independently audited.[2]
- **Why Jet should care — interpretation:** This validates the P2 thesis that useful agent ROI comes from real company tasks and live business context—not isolated prompts. The strongest audit candidates are workflows where an agent can read and write the client’s actual knowledge system while preserving permissions and traceability.
- **Revenue/offer action:** When selecting P2’s first 10 tasks, prioritize **knowledge-to-action workflows** such as meeting decision → page update → task/status change. Measure accepted-result rate, intervention, cost, and audit-trail completeness. This strengthens the existing Proof Sprint rather than creating a separate Confluence offer.

## 3. Safe outbound access is becoming a baseline control for code-running agents

- **Verified sources/date:** Vercel’s official security post and X announcement — **2026-08-11 05:19 Bangkok / 2026-08-10 22:19 UTC**, inside the scan window.[4][5]
- **What changed — fact:** Vercel made its Sandbox Egress Firewall free on every plan. Its stated control model includes default-deny destination policies, domain/CIDR restrictions, lifecycle-based access changes, host-side credential injection so secrets do not enter the microVM, and request forwarding for redaction, authorization, logging, and policy enforcement.[4][5]
- **Why Jet should care — interpretation:** An agent can leak data or misuse credentials without escaping its VM. For AI Leverage Audit delivery, “runs in a sandbox” is no longer sufficient evidence of safety; outbound destinations, secret placement, and action logging must be checked explicitly.
- **Revenue/offer action:** Add three evidence fields to the existing audit/proof-sprint checklist: **allowed outbound destinations, where credentials live, and whether each write/action is logged and reversible**. Use Vercel’s free firewall as one remediation path for relevant client builds, not as a new product line.
