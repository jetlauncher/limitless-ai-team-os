## 1) Privacy architecture is becoming a product requirement for long-running agents

- **Verified source/date:** OpenAI, **2026-08-20 02:00 Bangkok** (2026-08-19 19:00 GMT).[1]
- **What changed (fact):** OpenAI reaffirmed Zero Data Retention for eligible API customers and previewed **Private Safety Processing**, designed to improve safety across related agent interactions without giving OpenAI personnel access to the underlying content.[1]
- **Why it matters to Jet:** As agents take on longer, more autonomous workflows, “we do not train on your data” is too shallow.[1] Buyers need a concrete data-lifecycle answer: what is stored, where safety inspection happens, who can access raw content, and what happens across multi-step sessions.[1]
- **Revenue action:** Add a paid **Agent Data Boundary Review** to the AI Leverage Audit: retention mode, provider eligibility, prompt/output logging, human access, safety-processing path, connector data, and deletion evidence.[1] Failed controls become a privacy-remediation upsell.

## 2) NVIDIA published a usable blueprint for proving whether agent skills create value

- **Verified source/date:** NVIDIA Technical Blog, **2026-08-19 23:00 Bangkok** (16:00 UTC).[2]
- **What changed (fact):** NVIDIA released open-source **SkillEvaluator**, which compares the same agent task with and without a skill in isolated sandboxes. Its vendor-reported benchmark covered 300+ skills across 30+ products and measured correctness, discoverability, effectiveness, efficiency, and security; the reported lifts were +41, +40, +39, +35, and +1 points respectively.[2]
- **Why it matters to Jet:** NVIDIA’s controlled with/without-skill design directly validates the proposed Limitless **AI Workflow Proof Sprint** thesis: sell measured workflow lift, not a demo.[2] It also gives Jet a defensible first-party research format—before/after task evidence under controlled conditions.[2]
- **Revenue action:** If P2 is activated, base its 10-task rubric on the same controlled design: identical task, model, inputs, grading, and environment; vary only the workflow/skill.[2] Report accepted-result rate, time, token cost, human corrections, and security regressions.[2] Treat NVIDIA’s figures as vendor-reported, not universal guarantees.

## 3) Source governance is becoming enforceable infrastructure, not just prompt advice

- **Verified source/date:** AWS, **2026-08-20 05:13 Bangkok** (2026-08-19 22:13 UTC).[3]
- **What changed (fact):** Amazon Bedrock AgentCore Web Search connector v1.2.0 added per-request domain allow/deny lists and publication-date windows, enforced server-side. Runtime rules can narrow but cannot expand administrator policy; AWS also expanded availability to Ireland and Tokyo.[3]
- **Why it matters to Jet:** “Use reliable sources” can now be tested as an enforceable control rather than prompt advice.[3] This is directly relevant to audits involving current pricing, regulation, inventory, policy, or research—where an old or unapproved source can create customer harm.[3]
- **Revenue action:** Add a **Trusted Sources & Freshness** audit test: approved-domain policy, blocked-domain policy, maximum source age by workflow, server-side enforcement, citation trace, and failure behavior when no compliant source exists.[3]
