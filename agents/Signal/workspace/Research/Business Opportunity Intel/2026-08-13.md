## 1. Claude’s browser agent is becoming a persistent cross-device work surface

- **Verified source/date:** Claude official X announcement — Aug 12, 2026, 20:20 UTC.[1] Anthropic safety guidance — updated Aug 12/13, 2026.[2]
- **What changed — fact:** Claude in Chrome sessions can now continue across desktop, web, and mobile; conversations persist and skills/connectors work in the browser. The new Cowork side panel is available on Max and Team, with Pro rollout planned. Anthropic’s safety guide says browser agents remain exposed to prompt injection, screenshots can capture visible sensitive data, and admins should use restrictive site allowlists for sensitive workflows.[1][2]
- **Why it matters to Jet — interpretation:** This makes browser-based execution easier to teach and deploy, but it also turns browser permissions, visible data, approval mode, and allowed sites into concrete AI Leverage Audit controls—not abstract policy.
- **Commercial action:** Do not start a new build. If P2 is activated, add one **Browser Agent Safety Test** to the existing 10-task rubric: trusted-site allowlist, screenshot/data exposure, manual-vs-auto approval, connector permissions, prompt-injection response, and reversible actions. Sell failed controls as a remediation module.

## 2. A small open model can make document intelligence private and customizable

- **Verified source/date:** Cohere Labs technical release and Hugging Face model card — Aug 12, 2026.[3][4]
- **What changed — fact:** Cohere released **North Micro Vision**, a 2.4B-parameter Apache-2.0 open-weight vision-language model designed for documents, charts, tables, screenshots, forms, OCR, visual grounding, and multilingual inputs. The model supports native-resolution A4-page processing; public vLLM support is still listed as coming soon. Performance comparisons are vendor-reported.[3][4]
- **Why it matters to Jet — interpretation:** It creates a credible privacy-first option for Thai SMEs that cannot send contracts, invoices, forms, or internal documents to a hosted frontier model. The smaller model also makes customer-specific fine-tuning and local experimentation more realistic.
- **Commercial action:** If P2 is activated, benchmark one sanitized Thai document workflow—invoice extraction, contract obligation capture, or registration-form QA—against a hosted model. Use **accuracy, intervention rate, latency, and cost per accepted document** to decide whether a paid private-document remediation is justified.
