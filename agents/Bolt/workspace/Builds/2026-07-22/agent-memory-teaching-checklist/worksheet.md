# AI Team OS Worksheet: Agent Memory Sync

## Goal
Teach students to design a multi-agent memory routine that is inspectable, safe, and easy to recover after context loss.

## The 3-layer pattern
1. Agent daily note — what happened today.
2. Agent durable memory — stable facts and reusable workflows only.
3. Shared daily handoff — what other agents need to know.

## Verification checklist
- [ ] Every active agent has a non-empty daily note.
- [ ] Shared daily has a section with each active agent.
- [ ] No secrets/tokens copied into notes.
- [ ] No external side effects happened during memory sync.
- [ ] Any uncertain item is marked `Needs review`.
