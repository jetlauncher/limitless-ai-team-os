# Agent Write-Access Safety Gate

A local, printable v0 for Jet's AI Team OS classes and founder workflow reviews.

## Open/use

- Open `index.html` in a browser.
- Use the three checkboxes to score a proposed agent workflow.
- Click **Print / Save as PDF** for classroom handouts.
- Use `worksheet.md` as the copy-paste Obsidian/Notion version.

## Why this exists

Recent Signal notes surfaced a practical teaching gap: founders need a simple rule before agents get write access. This tool turns the risk signals into a classroom-ready safety gate.

## Files

- `index.html` — interactive printable single-page tool
- `worksheet.md` — markdown handout
- `data.json` — source/context data
- `verification.json` — generated after checks

## Safety

Local files only. No Telegram/email/posts/deploys/cron edits/external state changes.
