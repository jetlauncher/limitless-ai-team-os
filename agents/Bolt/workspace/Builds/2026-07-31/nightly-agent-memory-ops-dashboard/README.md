# Nightly Agent Memory Ops Dashboard v0

A local HTML dashboard generated by the 2:00 AM memory sync job.

## Open
Open `index.html` in a browser.

## What it shows
- 13 synced agent daily notes.
- Clean vs partial sync flags from local notes.
- Current recurring blockers found in recent Qwen/Oracle/Hermes/Shared Memory notes.

## Data
`snapshot.json` contains the machine-readable sync snapshot.
