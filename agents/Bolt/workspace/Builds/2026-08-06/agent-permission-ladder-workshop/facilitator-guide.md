# Facilitator Guide — Read / Draft / Action

## 10-minute class flow
1. **Show the ladder (2 min):** READ creates insight, DRAFT creates reviewed output, ACTION changes the world.
2. **Founder scenario (3 min):** Ask students where they would place an email agent, content agent, finance agent, or CRM agent.
3. **Red-team moment (3 min):** What goes wrong if the agent has posting/payment/delete rights too early?
4. **Commitment (2 min):** Each student writes one permission boundary for their own workflow.

## Best current example from Jet's system
- Threads auto-publishing was stopped on 2026-08-05.
- Content agents can still draft, but no agent should post/schedule Threads content unless Jet explicitly re-approves it.
- This is the ladder in practice: keep value at DRAFT until ACTION has a named owner and approval rule.
