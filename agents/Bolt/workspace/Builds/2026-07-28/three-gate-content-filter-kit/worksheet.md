# The 3-Gate Content Filter Kit

Built: 2026-07-28 by Kelly nightly cron  
Source: `Agents/Oracle/Ideas/Hourly Shortform/2026-07-28-2300-hourly-shortform.md`

## Use case
A printable / copy-paste worksheet for Limitless Club or Eden Academy-style classes. It helps Thai SME founders judge whether a post is worth publishing before asking AI to polish it.

## The gates

| Gate | Question | Score |
|---|---|---|
| 1. Stop the scroll | Does the first sentence use a specific number, pain, audience, or contradiction? | /3 |
| 2. Give real value | Does the post educate, entertain, or inspire with one clear takeaway? | /3 |
| 3. Make it shareable | Would a founder send this to a cofounder or team member at 10pm? | /3 |

**Publish threshold:** 7/9 or higher. If any gate is 0, rewrite before posting.

## Student exercise
1. Pick one draft post.
2. Score each gate from 0 to 3.
3. Rewrite only the lowest-scoring gate.
4. Run the AI reviewer prompt.
5. Decide: publish, revise, or kill.

## AI reviewer prompt
```text
Act as my content editor for Thai SME founders. Score this draft against 3 gates: stop the scroll, give real value, make shareable. For each gate, give 0–3, one reason, and one rewrite. Do not change my meaning. Draft: [paste draft]
```

## Facilitator note
Frame this as a decision system, not a writing trick: the goal is fewer mediocre posts and more posts with a clear audience, proof hook, and forwarding reason.
